## 🏛 About SGSS Org

**SGSS Org** is the parent organization and central holding company for all software products, gaming bots, audio streaming networks, and serverless developer infrastructure created by Walusimbi Leon. 

Operating under the belief that community digital tools should be ultra-fast, accessible, and resilient, SGSS hosts over **22 production microservices** handling more than **480,000 monthly invocations** with a verified **100.00% zero-downtime reliability** record across Cloudflare's global edge network (330+ locations).

## 💻 Local Development

```bash
git clone https://github.com/Walusimbi-Leon/walusimbi-leon-portifolio.git
cd walusimbi-leon-portifolio
npm install
npm run dev
```

To build and deploy:

```bash
npm run build
npx wrangler pages deploy dist --project-name walusimbi-leon-portifolio --branch main
```
